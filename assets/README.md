# Assets placeholders

Remplacez les fichiers placeholders ci-dessous par vos visuels finaux sans changer les chemins:

- `assets/sprites/m1.png ... m5.png` : sprites pixel des membres
- `assets/icons/m1.svg ... m5.svg` : icônes portrait
- `assets/collectibles/*` : icônes des collectibles
- `assets/bg/*` : backgrounds/parallax optionnels
- `assets/audio/*` : previews locales (optionnel)

Le projet fonctionne sans ces fichiers grâce aux fallbacks UI/Canvas.
